일하는 방식

클론 챗봇 8일간 실제 진행 순서

  1. 브리프

    무엇을 왜 만드는지, 누구의 어떤 문제인지 먼저 글로 정리한다. 코드는 아직 없다.

  2. PRD

    브리프를 기능 요구사항으로 쪼갠다. 이번에 안 만들 것도 명시한다.

  3. 아키텍처 명세

    데이터 흐름과 구조를 265줄로 확정한다. AI에게 시키기 전에 판단을 내려둔다.

  4. 적대적 리뷰

    내 설계를 일부러 공격하는 리뷰를 255줄 붙인다. 구현 전에 무너뜨려 본다.

  5. 에픽 · 스토리 단위 구현

    기능을 스토리로 나누고 하나씩 끝낸다. 스토리마다 구현 기록을 남긴다.

  6. 회고와 보류 목록

    에픽이 끝날 때마다 회고를 쓰고, 못 한 일은 지우지 않고 보류 목록으로 추적한다.
